# 큰 표지(크게 보기용) 올리기 사양 — 업로더 구현용

> 웹 v2.6 은 소설 상세에서 표지를 누르면 화면에 맞춰 크게 보여 줍니다(확대·축소 없음).
> `novels.cover_large_path` 가 있으면 그 이미지를, 없으면 목록용 표지(`cover_path`, 480×720)를 띄웁니다.
> 이 문서는 업로더(upload.py · Flask 업로더)가 큰 표지를 올릴 때 지켜야 할 형태입니다.

## 1. DB
- `supabase/migration_006_cover_large.sql` 실행 → `novels.cover_large_path text` 추가 (다시 실행해도 안전)
- 값 형식(검사 제약): `^novels/[a-z0-9_-]+/cover-[0-9a-f]{8,64}-l\.(webp|jpg)$`
  - 예: `novels/nv-76dd6bd5/cover-3833f33b3ebb9f03-l.webp`
- 칸이 없으면(006 전) 웹은 그냥 목록용 표지로 크게 보기 → 업로더도 칸이 없으면(PostgREST `42703`) 큰 표지만 건너뛰고 안내

## 2. 파일
| 항목 | 값 |
|---|---|
| 저장소 | 버킷 `content`, 경로 `novels/<소설ID>/cover-<해시>-l.webp` |
| `<해시>` | **목록용 표지와 같은 값** (원본 이미지 해시 앞 16자, 지금 `cover_hash`) → 두 표지가 항상 짝으로 바뀜 |
| 비율 | 2:3 (목록용 표지와 같은 자른 영역) |
| 크기 | 긴 변 최대 1800px (1200×1800 안), **원본보다 키우지 않음** (업로더 자르기 결과가 800×1200 이면 그대로 800×1200) |
| 형식 | WebP, 품질 85, method 6, EXIF 회전 반영 후 메타데이터 제거, RGB(투명 있으면 RGBA) |
| 용량 | 400KB 넘으면 품질 75 로 다시 저장 (그래도 넘으면 그대로) |
| Content-Type | `image/webp` |
| Cache-Control | `public, max-age=31536000, immutable` (파일 이름에 해시가 있어서 바뀌면 이름이 바뀜) |
| 업로드 | `POST /storage/v1/object/content/<경로>` + `x-upsert: true` (지금 표지 올리기와 같은 방식, service role 키) |

- 원본: 업로더가 받아 둔 원본(`_covers/<소설ID>/original.*`)을 같은 자른 위치(`cover.json` crop)로 잘라서 만들면 가장 선명함. 원본이 없으면 표지 파일(`novels/작품.jpg` 등)에서 만들기
- 목록용 표지(480×720)는 지금과 그대로

## 3. 순서 (표지가 새로 생기거나 바뀔 때)
1. 목록용 `cover-<해시>.webp` 와 큰 `cover-<해시>-l.webp` 를 **둘 다** 올림
2. 소설 행을 **PATCH** 로 한 번에 갱신 (upsert 아님 — 필수 칸이 없으면 실패함)
   ```
   PATCH /rest/v1/novels?id=eq.<소설ID>
   { "cover_path": "...", "cover_hash": "<해시>", "cover_large_path": "...-l.webp" }
   ```
3. 옛 표지 파일 두 개(`cover-<옛해시>.webp`, `cover-<옛해시>-l.webp`)를 지움
- 큰 표지 만들기·올리기가 실패하면 `cover_large_path` 는 `null` 로 두고 목록용만 반영 (웹은 목록용으로 크게 보기)

## 4. 이미 올라간 표지 (채워 넣기)
- `cover_hash` 는 같은데 `cover_large_path` 가 비어 있는 소설 → 큰 표지만 만들어 올리고 `cover_large_path` 만 PATCH
- 계획 화면에는 "큰 표지 추가" 로 표시 (회차 변경 없음)

## 5. 다른 명령과의 관계
- `--replace` · `--replace-all`: 지금처럼 `cover-` 로 시작하는 파일은 지우지 않음 (큰 표지도 해당)
- `--delete`: `novels/<소설ID>/` 아래를 모두 지우므로 큰 표지도 함께 지워짐
- 폴더에서 표지 이미지를 빼도 올라간 표지 두 개는 그대로

## 6. 웹 쪽 동작 (참고)
- 목록·홈·상세에는 목록용 표지만 씀. 큰 표지는 **표지를 눌렀을 때만** 서명 주소를 받아 불러옴
- 서명 주소는 7일짜리로 기기에 기억, 서비스 워커가 토큰을 뺀 경로로 저장 → 한 번 본 큰 표지는 오프라인에서도 보임
- 소설 목록을 불러올 때 `cover_large_path` 칸을 같이 받음 (칸이 없으면 빼고 다시 받음)
