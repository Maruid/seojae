# 장르·태그 규칙 사양 — 업로더 구현용

> migration_007 부터 소설 장르는 **정해진 목록에서만** 고릅니다. 목록에 없는 말은 태그로 갑니다.
> DB 트리거가 마지막에 한 번 더 정리하지만, 업로더(upload.py · Flask 업로더)도 같은 규칙으로 맞춰서
> 계획 화면에 보이는 값 = 실제로 저장되는 값이 되게 해 주세요.

## 1. 장르 목록 (보이는 순서)
판타지, 현대판타지, 무협, 로맨스, 로맨스판타지, 라이트노벨, SF, 대체역사, 스포츠,
공포, 미스터리, 추리, BL, GL, 현대, 퓨전, 게임, 역사 (18개)

| 별칭 | → 목록 이름 |
|---|---|
| 현판 | 현대판타지 |
| 로판 | 로맨스판타지 |
| 호러 | 공포 |

- 원본은 DB 표 `genre_list(name, ord)` · `genre_alias(alias, name)` (migration_007).
- 업로더는 시작할 때 두 표를 읽어서 씀 (service role 키, `GET /rest/v1/genre_list?select=name,ord&order=ord`, `GET /rest/v1/genre_alias?select=alias,name`).
  표가 없으면(007 전, PostgREST `42P01`/`PGRST205`) 위 기본값을 쓰고 "migration_007 전" 안내.
- 목록을 바꾸고 싶으면 SQL 로 표를 고치면 됨 → 웹·업로더·트리거 모두 따라감.
- **미스터리 ≠ 추리, 현대 ≠ 현대판타지** (따로 있는 장르). 일반·드라마는 목록에 없음 → 태그로.

## 2. 비교 방법
- 비교 키 = 모든 공백 제거 + 소문자: `key(s) = lower(re.sub(r'\s+', '', s))`
  - "현대 판타지" = "현대판타지", "sf" = "SF", " 무협 " = "무협"
- 순서: ① 목록 이름과 키가 같으면 그 이름 ② 별칭과 키가 같으면 그 별칭이 가리키는 이름 ③ 둘 다 아니면 **목록에 없음**

## 3. 정리 규칙 (`clean_genres(genres, tags)` 와 똑같이)
1. **장르**: 입력 순서대로 2번 비교 → 목록 이름으로 바꿈. 중복은 처음 것만. 최대 10개.
2. **목록에 없는 장르** → 태그 후보로 옮김(moved). 예: "퓨전무협", "일반", "드라마"
3. **태그**: 기존 태그 먼저, 그다음 옮긴 장르 순서로
   - 앞의 `#` 제거, 모든 공백 제거 ("성장 물" → "성장물")
   - 빈 값·중복 제거
   - 20자 넘으면 버림, 20개 넘으면 나머지 버림 (dropped → 계획 화면에 경고로 표시)
4. **genre** (예전 앱 호환용 한 칸) = 정리된 장르의 첫 번째 (없으면 null). 화면에서 고르는 값이 아님.

> 다중 장르는 그대로입니다. `genres` 배열이 진짜 장르, `genre` 는 옛 앱 때문에 남겨 둔 첫 장르 복사본일 뿐입니다.

### 예
| 입력 genres / tags | 결과 genres / tags |
|---|---|
| `["현판","퓨전무협"," 무협 "]` / `["a"]` | `["현대판타지","무협"]` / `["a","퓨전무협"]` |
| `["현대 판타지","판타지","판타지"]` / `[]` | `["현대판타지","판타지"]` / `[]` |
| `["일반","드라마"]` / `["#일반"]` | `[]` / `["일반","드라마"]` (⚠ 장르 없음) |

## 4. 업로더에 넣을 곳
| 곳 | 할 일 |
|---|---|
| 메타 정리(`clean_meta`) · `--meta` 반영 | 올리기 전에 3번 규칙 적용 후 PATCH/RPC |
| 소설 목록 로컬 메타(`novels_map` 등) | 예전 장르가 남아 있으면 **읽을 때 정리** — 안 그러면 `meta_dirty` 로 옛 값이 다시 올라감(트리거가 고치긴 하지만 매번 "변경"으로 보임) |
| 편집 화면(Flask UI) 장르 입력 | 목록에서 고르기(칩) + 타이핑 자동완성(앞부분 일치 → 중간 일치 → 별칭). 목록에 없는 말은 "#… 태그로 넣기" |
| 계획 화면 | 바뀌는 장르는 `현대 판타지 → 현대판타지`, 태그로 옮기는 건 `장르→태그: 퓨전무협`, 버리는 건 경고, 장르가 비면 `⚠ 장르 없음` |
| 비교(변경 여부) | 정리한 값끼리 비교. 순서까지 같아야 "변경 없음" |

## 5. DB 쪽 (참고)
- 트리거 `novels_clean_genres`: novels 의 genres·tags 를 쓸 때(insert · update of genres, tags) 자동 정리 + genre = genres[1]
  → 업로더가 규칙을 빼먹어도 저장값은 항상 정리됨 (마지막 안전망)
- 관리 RPC `admin_update_novel` 도 같은 트리거를 거침
- 함수 `genre_key(text)`, `clean_genres(text[], text[])` 는 SQL 에서 직접 써도 됨:
  `select * from clean_genres(array['현판','퓨전무협'], array['a']);`
